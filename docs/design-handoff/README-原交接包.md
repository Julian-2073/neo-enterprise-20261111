# NEO 前端演示开发交接包

日期：2026-09-29  
目标：依据已确认六页图片，在用户另一台电脑的现有代码仓库中实现前端演示。  
本包只有实施说明、模拟数据和图片，没有网页开发代码。

## 文件用途

- [开发实施说明.md](开发实施说明.md)：主文档，范围、视觉、口径、每页功能、聊天行为、实施顺序、验收。
- [给开发智能体的任务说明.md](给开发智能体的任务说明.md)：可直接复制发送的开发任务。
- [demo-data.json](demo-data.json)：统一演示数据与预设情景，供实施智能体适配现有工程。
- images/：六张最新单页图及高清总览。

## 使用方法

1. 将本目录或压缩包转到目标电脑，解压在代码仓库外或仓库 docs/ 下。
2. 在目标代码仓库启动开发智能体。
3. 发送“给开发智能体的任务说明.md”的正文，并告知本交接包的实际目录位置。
4. 智能体先检查现有工程，再依主文档实施；数字以文档和JSON为准。
5. 不需要本机路径，也不需要访问原飞书资料，文件包本身足以指导本期前端实现。

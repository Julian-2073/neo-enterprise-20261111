# 给开发智能体的任务说明

请在我提供的现有代码仓库中，根据同目录的《开发实施说明.md》、demo-data.json 和 images/ 内六张单页图，完成 NEO / GrowthOS 的可交互前端演示。

先阅读仓库 AGENTS.md 和现有工程结构，复用已有技术栈、路由、组件、图表与主题；不要擅自重写工程。实现以下六页：首页、经营分析的人/货/场、经营联动总览、未来与决策中心。

视觉沿用图片的简洁白色风格；页面里的按钮、图表、筛选、证据详情、对话输入和草案状态必须可操作，不能用整张截图代替网页。五处智能体统一为“上方小型建议行动按钮、中间对话、下方输入框与发送”，联动页支持协同/指定智能体。

本期只做前端：使用统一模拟数据和本地预设回复，不做后端、数据库、真实模型调用、真实企业数据采集、投放、采购、任务下发或消息推送。用户补充是待核实线索，预测是模拟区间，动作只有本地草案与演示确认。

范围与数据口径以《开发实施说明.md》优先于图片小字。尤其修正首页库存总额、不同页面数据范围、当前周期比值与单周比值、三类SKU达标率及预测纵轴。不要新增完整周报页；保留规划中入口即可。

按文档实施顺序推进，完成六页跳转和交互，再做桌面与移动基础适配，运行工程已有的必要检查并保存页面截图。完成后说明启动方式、实现页面、模拟能力、口径修正、验证结果与仍未接入的能力。

这是界面原型开发任务，不要求部署、发布或连接真实业务系统。可逆实现选择按现有工程习惯完成，不必逐页停下来询问确认；若仓库缺失或关键约束冲突，请指出具体阻塞。

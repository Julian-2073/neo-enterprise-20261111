# 项目智能体运行预算限制已移除

按用户确认的“整个项目智能体”范围，运行时不再按累计 token、模型调用次数、工具调用次数、市场检索次数或后台每日 200,000 token 拒绝任务。单次模型请求也不再默认发送项目固定的 max_tokens。

新增运行的预算字段使用 JSON null 表示没有项目上限，公开运行记录标为 budgetPolicy=unlimited；没有用更大的有限数字冒充取消限制。现有模型调用日志、实际用量、来源引用、完成原因和历史失败记录继续保留。

原有数值预算请求仍可读取和校验，运行时忽略其中的消费上限。旧任务的固定输入和调用记录不改写；旧预算失败可由用户显式恢复，未批量重启历史失败任务。

## 继续生效的运行边界

- 模型供应商的账户额度、默认输出设置和上下文能力由供应商决定，项目代码不能取消。
- 市场检索的 0 值仍表示未启用。取消检索次数预算不会开启尚未授权或未配置的检索服务。
- 取消、已完成响应重放、计费状态未知时禁止重发、模型版本校验、企业和资料范围校验继续生效。
- 任务超时、队列领取尝试次数、自动监控频率及业务规则仍有效；这些决定任务收尾、调度或业务计算。
- 经营投放金额、现金、履约和库存约束仍属于方案计算输入。
- 单独执行的 provider benchmark CLI 仍按执行者主动指定的 max_calls / max_tokens 控制该次评估；正常项目智能体不受此脚本约束。

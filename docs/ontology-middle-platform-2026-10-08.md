# NEO 数据与智能中台重构

交付日期：2026-10-08。主入口：`/data/ontology`。独立本地预览：<http://127.0.0.1:3158/data/ontology?businessId=test-a&dataNature=demo>。

本轮把原有多功能工作台重新组织为一个企业中台：数据与知识、逻辑与执行、运行管理。总览用“接入 → 治理 → Ontology → 规则 → 智能体”表示实际流程，显示当前企业、资料性质、发布状态和经营页面所用版本。当前经营代次与旧快照均支持回读；不同企业、经营导入与演示数据分别读取。

## 可操作能力

| 模块 | 本轮可用行为 | 生效条件 |
| --- | --- | --- |
| 数据接入 | 经营 CSV / 手工录入、标准模板、正式校验、确认入库和数据版本生成；合并展示两条存储链路的接入记录 | 复用现有权限和导入约束；原始事实不由治理建议改写 |
| 数据治理 | 读取 1 MiB / 1,000 行以内 CSV，剖析空值、完全重复行、不同值与类型；按已发布属性/字段映射匹配；保存报告并按范围回读 | 字段类型是剖析建议，正式约束仍由后续校验执行 |
| Ontology | 可选择、拖动、缩放的对象关系图；对象主键、属性、关联关系详情；展开编辑类型、关系和映射 | 已发布定义描述结构；实际对象需选择有效投影 |
| 后端规则 | 统计窗口、客户转化口径、草稿影响预览、冲突检查、配置发布和新经营版本 | 历史版本保持可回读 |
| 智能体 | 专业启停、职责、重点要求、工具权限；关联当前模型连接 | 配置作用于新任务；经营代次继续冻结该代次使用的业务规则 |
| 模型与密钥 | 三家提供方的 OpenAI compatible 连接；服务端 AES-GCM 加密；认证/模型目录检查；启用连接供新任务使用 | 浏览器不回读原密钥；目录检查不证明实际生成成功 |
| 工作流 | 可点击的治理节点画布；编辑名称、治理要求、启用可选模型步骤、保存新版本、运行确定性预检 | 当前是固定治理流程的节点配置；人工确认、正式校验、确认入库关卡保留 |
| 运维 | 原有函数、动作、对象探索、运行结果与健康检查入口 | 运行失败保持失败；内部选择不表示采购或投放已执行 |

## Agent 与开源选择

推荐沿用现有 LangGraph 经营执行器，并把数据治理做成轻量的独立流程。现有确定性剖析可先使用；模型辅助只接收字段名称、统计摘要及对象定义，不发送原始 CSV 行值。返回的映射只能使用给定的来源字段和目标属性，警告文本也经结构校验。输出由人确认，当前不自动应用映射或提交入库。

| 一手来源 | 可借鉴 / 候选接入 | 当前状态与成本 |
| --- | --- | --- |
| [OpenMetadata](https://github.com/open-metadata/OpenMetadata) | 目录、质量、血缘、业务语义统一管理 | 架构参考，未安装。完整部署会增加服务维护、连接器适配与元数据同步成本 |
| [OntoGPT](https://github.com/monarch-initiative/ontogpt) | 按 schema 从文本抽取实体与关系，结合 ontology grounding | 候选适配器，未接入。企业商品/渠道等需要自己的 LinkML 模板和词表；不能直接把现成领域词表当企业模型 |
| [LangGraph](https://github.com/langchain-ai/langgraph) | 检查点、恢复、Agent 执行步骤 | 现有经营 Agent 已使用。本轮治理预检采用确定性步骤与可选的模型调用，尚非任意 DAG 编辑器 |

这些仓库是研究与架构参考。本轮没有安装它们的整套产品，也没有把参考或候选适配器标为已接通。

## 模型配置与运行边界

连接范围为企业 × 资料性质，支持 OpenAI、DeepSeek、阿里云百炼的已注册接口。保存连接创建不可变配置；启用另一连接只影响新任务。任务载荷保存 `modelProfileRef`，不保存原密钥。执行服务凭已有服务认证从中台读取该配置，凭证只进入执行内存；提供方 URL 从已注册列表中选择，浏览器不能指定任意内网地址。

服务端部署需要 `NEO_CONFIG_ENCRYPTION_KEY` 和 `NEO_CONTROL_URL`。本地稳定启动器为每个独立输出目录保存权限为 0600 的加密主密钥，并为服务双方设置同一个本地中台地址。加密主密钥丢失或被替换会使旧凭证不可解密，备份运行状态时应妥善保管该文件。浏览器无密钥查看入口。

本轮界面验收只保存“验收连接（模拟密钥，未启用）”。没有启用这个连接，没有提交真实付费生成请求。真实模型认证、生成结果和真实企业治理准确性尚未验收。可选治理模型请求有 45 秒超时、1,500 输出 token 上限；经营智能体继续沿用现有调用账本与任务预算。

数据库 / API 连接器目前显示为待接入。输入上传、正式入库和模型配置已可操作；没有把未实现的连接器呈现为可用。工作流提供固定的数据治理步骤配置，尚不支持任意节点、分支或任意代码执行。

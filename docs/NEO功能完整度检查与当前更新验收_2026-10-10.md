# NEO 功能完整度检查与当前更新验收

日期：2026-10-10。正式主仓：`NEO后端交接包2026-09-30/growthos-dashboard`。

## 结论

NEO 已具备导入、冻结经营资料、证据下钻、专业研判、预测、情景比较、保存决策及部分执行复盘的实现。当前最值得优化的是：让新企业能够自行准备数据；让常见经营问题稳定得到正确答案；把不同方案入口的选择、执行和复盘连成一致流程。

当前工作树中的未提交更新已纳入检查，不能用早期“尚未接入”文档描述今天的全部功能。本轮完成其中一个实际使用断点的补齐，并构建、启动和检查了当前本地版本。这里的“可运行”不代表已完成真实企业试点、预测精度或经营收益验收。

| 决策、执行与复盘 | 主经营决策具有执行凭据登记、投入/数量核对、实际对照、凭据更正核验与经验确认后端；原预测页可以填写负责人及观察日期 | 三条路径完成度不一致：普通方案可回看执行结果，候选模型选择主要以列表回读，补货优化选择的评估仍明确 `executionStatus=not_recorded`、实际履约和行动利润为 null。建议统一选择记录和执行结果入口；凭据用可查找、可选择的来源记录代替手填编号 | P1 |
| 经营周报 | 汇总当前资料范围的方案、保存选择、理由、待验证条件，能回到原方案 | 更接近决策摘要，还不是完整周期复盘。应加入负责人、观察日期、未执行原因、实际投入/结果、上周待核问题的结转，并提供保存的周报版本和期间选择；无需扩成复杂审批系统 | P1 |
| 预测可靠性 | 基线预测、供给约束、候选模型对照、历史误差/校准状态、后续实际评估与保存版本 | 当前模拟快照返回 `no_paid_series`，历史记录的可知时间不满足回测边界。需要新企业冷启动提示、最少有效历史要求、未来滚动预测与实际对账流程；不能补写当时不可知时间来制造回测成绩 | P1 |
| 我的客户 | 身份关联、去重旅程、成熟观察窗口、阶段人数与转化口径、渠道/商品范围和证据 | 观察和诊断较完整，具体业务跟进仍主要通过建议表达。优先完善“异常落在哪个客群/阶段 → 需要核对哪些记录 → 保存跟进与观察结果”，并说明聚合行为无法支持名单级动作的场景 | P2 |
| 供应链与库存 | 商品/仓库库存、在途、供给规则、历史状态、调拨/补货情景；扩展引擎考虑酒店容量和制造约束 | 主界面里传统货盘角色和扩展行业单位的衔接还需统一。应把缺目标、零可售、已到未上架、预计缺口分别呈现，并让供应条件、执行凭据和结果在同一个经营任务中回读 | P2 |
| 渠道、竞品与外部信息 | 渠道费用和订单核算、原网页读取记录、保存来源、相关性判断和知识监控配置 | 资料存在、原网页已读取、断言已核验、适用于本企业是不同状态，应分别表达。完善来源失效、相关性待确认、观察更新时间和如何转为一个可验证经营假设；本次运行未开启市场检索或自动监控 | P2 |
| 企业实际交付 | 企业成员访问校验及 admin/importer/reader 写入限制；配置发布、版本、历史证据和本地构建指纹 | 尚需可用的企业开通/成员管理流程，以及真实数据对账与连续经营周期验收。现有权限校验不是完整企业交付证明；当前 v0.1 不需要先做复杂多角色平台 | 后续交付阶段 |

建议开发顺序：**数据准备到第一份可信经营状态 → 常见问题稳定回答 → 统一选择/执行/复盘 → 周报结转 → 预测与后续实际连续验证**。先完成一个企业、一个问题、一个周期的闭环，再决定接口自动接入或行业扩展范围。

## 二、本轮已检查的已有更新

检查了工作树里的任务状态同步、JSON 完整性、已完成响应重放、回答与证据校验、完整分析恢复、首页语义修正、AI 三方案以及预算限制调整等更新，并运行当前代码的回归检查。

预算策略保留当前项目的 `unlimited` 设置；取消、状态未知时的重发约束、企业/资料范围及业务计算约束继续存在。本轮没有恢复旧预算、批量重启旧失败任务或重新生成历史回答。

本轮新增修复在 `components/neo-demo/ai-scenario-options.tsx`：

1. 先显示已经保存的 AI 建议，再执行方案计算。计算服务失败时，建议及其依据不消失。
2. 自动计算失败后保留明确状态，提供“重新计算与检验”，避免页面反复发起失败写入。
3. 等待中的建议可取消；符合后端恢复条件的失败/取消任务可继续，沿用原任务身份。
4. 取消或恢复尚未确认时继续回读状态，避免提前开放新生成按钮。
5. 新生成请求在网络中断后沿用同一 requestId，利用既有后端幂等机制，避免创建第二个模型任务。
6. 只读成员不触发计算、取消或恢复写入；切换资料范围时继续丢弃过期回包。

新增行为验证：`tests/scenario-options-ui.test.mjs`。修改前先复现了“已生成建议被隐藏”和“没有取消入口”，修改后测试通过。

## 四、明确保留的实质缺口

- 已保存 AI 方案 C 声称“无已核验外部原文”，但同一记录有外部来源目录及两项引用。当前页面可以回读它，不能因此认为该表述正确。本轮没有覆盖或重新生成原回答；建议的事实一致性应作为下一轮重点。

- 本轮没有验证新的付费模型调用、外部实时检索、自动监控、真实企业执行结果、生产权限配置或线上部署。

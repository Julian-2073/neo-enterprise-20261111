# 老板工作台前端调整 · 2026-09-04

## 本轮采纳的修改意见

- 保留浅蓝色视觉语言、GL-AI增长系统与无极画廊演示场景。
- 将长页面拆成老板首页、当前经营、经营周报、未来预测、每日简报五个入口。
- 首页呈现最近数据周的判断、成交事件、本周重点、预测摘要与简报入口。
- 当前经营保留全周期汇总和4A脉搏；5A理论与漏斗默认折叠为证据。
- 周报以明确的统计周为单位，指导下一周行动；切换周不混用全周期金额。
- 预测独立展示三种情景、4/8/12周区间、假设与朴素外推对照。
- 每日简报提供需求、内容、渠道分类，以及相关性和验证思路。
- 行动和复盘归入周报；简报可加入待安排研究清单。
- 不把5A、自动周报或预测包装为独有能力；聚焦低负担、可解释的增长经营流程。

## 时间与数据纪律

- 最新数据周不等于实时自然周；显示统计日期与下一周行动日期。
- 周日历结束不代表数据完整；明确提示周完整性待核验。
- 缺少相邻周或分母为零时，不生成环比或滞后比率。
- 聚合事件不等于去重人数、同一批客户转化或真实未成交客户存量。
- 当前经营金额为全数据周期，不作为单周金额使用。
- 预测区间是模型假设下的估算，未证明真实覆盖率；情景不是行动收益承诺。

## 本轮边界

- 不改数据库、接口与依赖；不接LLM、真实新闻源、自动推送。
- 示例数据继续通过现有载入流程使用；不会自动替换已有数据。
- 行动状态、复盘与研究清单仅本次浏览保留，不声称已持久化。
- 周报是现算预览，不声称存在已保存的历史快照。
- 仅本地预览，不自动覆盖已经公开分享的版本。

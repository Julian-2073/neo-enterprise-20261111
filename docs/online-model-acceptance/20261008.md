## 本轮修复与保护

- TS 与 Python 任务识别排除否定的“不要研判/分析”等字样，事实查询不被误提升为完整审查。
- 简单订单查询只传递所问指标的完整性状态与必要限制，保留真实缺口；不把已录入计数理解为整个期间无缺口。
- 数量追问保留企业、商品、渠道、期间、新旧版本提示和约束，不重复历史失败调查档案；原始会话及失败轮次完整保存。
- 主张校验材料以短引用复用完全相同的工具元数据，每条证据仍保留独立范围、位置与完整原值；没有降低语义校验要求。
- 专业运行兼容没有 history 字段的旧请求。
- 按用户追加要求，本轮手动分析临时关闭上下文 UTF-8 预留拦截。开关只匹配明确的本地在线验收企业与 demo/analysis 请求；模型次数、累计实际用量、未知调用保护、逐条账本继续生效，默认关闭。环境变量为 `NEO_ONLINE_ACCEPTANCE_CONTEXT_UNLIMITED=true`、`NEO_ONLINE_ACCEPTANCE_BUSINESS=<验收企业>`，并要求 `NEO_AGENT_EXECUTION_MODE=live`。
